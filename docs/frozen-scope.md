# 能力边界与不做清单

## 定位

Honest Boy 是本地 AI 编程智能体 CLI。它负责把模型动作限制在工作区内，
并把“完成”从模型自述改成 Gate 对验证器证据的判定。它不负责把模型变成不会犯错的程序员。

## 明确做

- 工作区内的读写、搜索、补丁编辑与 shell 执行
- 构建 / 测试 / 静态检查验证，并把原文与哈希固化为证据
- Gate 门禁、终态机、Receipt 哈希链、`hb verify` 校验
- 会话落盘与恢复、检查点回退、计划模式、自动提交、上下文压缩
- TUI 与单次 CLI 两种使用方式；三套模型协议
- 本地的统计、探针、脱敏导出与过期清理

## 明确不做

| 不做 | 原因 |
|---|---|
| 遥测、云同步、账号体系 | 定位是本地工具；除配置的模型端点外不主动外发数据 |
| GUI / 编辑器插件 | 保持单文件 CLI 与终端工作流 |
| 远程执行、云端沙箱 | 代码与命令只在本机运行 |
| 操作系统级沙箱 | 文件工具用 `os.Root` 限制路径；`shell` 以当前用户权限运行，能做什么取决于操作系统账户 |
| 绝对防作弊 | 用户始终可以修改本地二进制、会话文件或验证器本身；哈希链只能证明“落盘后未改动”，不能证明“用户没有权限改” |
| 保证代码正确 | 验证器只覆盖它实际检查的内容；没被测试覆盖的逻辑仍可能出错 |
| 内置模型 / 免费额度 | 模型端点、密钥与费用由用户自行提供 |

## 安全边界的具体含义

- **路径边界是硬的**：绝对路径、`..`、盘符相对路径、编码绕过都会被拒绝（`HB-SBX-003`），
  没有“批准后访问任意路径”的开关。需要外部文件时先复制进工作区。
- **审批不是权限提升**：`approval.exec=auto` 只是让普通命令免弹窗；高危命令（`rm -rf /`、
  `git push --force` 等）始终需要单次显式授权。
- **密钥只存环境变量**：配置里只有变量名；日志与会话做脱敏，导出可用 `--redact`。
- **会话是本地的**：jsonl 存在用户配置目录；`hb gc` 清理过期数据，`hb sessions rm` 立即删除。
