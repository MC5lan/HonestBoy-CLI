# 30 天自用记录模板

用途：满足 v1.0 的“30 个连续自然日真实自用”门禁。模板本身不是证据；只有真实发生过的使用才能填。
开发期零散记录仍放在 [`dogfood-log.md`](dogfood-log.md)，不重复搬进本表。

## 规则

- 连续 30 个自然日，每天至少 1 次真实任务；不能补写、不能合并多天。
- 只写自己实际遇到的“不舒服”；没有就写“无”，不要为了凑数编问题。
- 每条必须能对应到具体版本（`hb --version`）和证据（提交、测试、日志或截图路径）。
- 密钥、私有代码、客户数据必须脱敏；不要粘贴完整 API key。
- 某天确实没用：写“未使用”并说明原因；连续天数从下一天重新开始，或经产品决定延长窗口。
- 30 天结束时汇总：出现频率最高的 3 个不适、已修/不修理由、是否仍愿意日常使用。
